# 90-second demo script

Use the seeded sample client and record the final screen at 1440×900.

| Time | Screen | Narration |
| --- | --- | --- |
| 0–10s | Landing page and sample report | “Your best maintenance work is usually invisible. RetainerProof turns it into client-visible value.” |
| 10–27s | Quick Add | “Choose the client, pick the work, and save a factual note in about ten seconds.” |
| 27–39s | Rewrite for client | “For a rough note, explicitly ask AI for client-friendly English. Nothing is saved until you approve it.” |
| 39–53s | Client coverage | “RetainerProof checks the public site and important URLs every day, then records exactly what it observed.” |
| 53–72s | Report draft | “At month-end, completed work, checks, prevention, and recommendations become a draft you control.” |
| 72–84s | Shared report and PDF | “Finalize an immutable revision, send a private link, and let the client download the PDF.” |
| 84–90s | Pricing | “Start with three clients for five dollars a month.” |

Do not claim uptime, threat prevention, automatic WordPress updates, backup verification, or form testing.
